# The Agent's Uh-Oh — underthinking

One word an agent says when it has no idea what to do: `underthinking`. Not overthinking — underthinking. The machine caught mid-task, admitting it simply did not think enough, blurting its confession out loud instead of stalling in silence. It lands instantly, it repeats well, and it is the honest sound of an agent that ran out of thought before it ran out of task.
